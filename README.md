# Playing to Lose: Subgame-Perfect Equilibria in Three-Player Sequential Round-Robin Tournaments with Non-Monotone Prizes: Supplementary Calculations

In this repository, you will find the supplementary calculations for both the main model (non-monotone prizes) and the monotone prizes, each available as an HTML file and a wxMaxima notebook.

If you simply want to read through the math and results, the HTML versions are highly recommended for quick and easy viewing.

To actively interact with the code, you will need to download and install the free open-source computer algebra system, wxMaxima. Once opened, you can evaluate the notebooks' cells to reproduce the mathematical derivations and equilibria calculations step-by-step.

[Click here to display the HTML version of the calculations (non-monotone prizes) in your web browser](https://stokehol.github.io/Playing-to-Lose/Playing%20to%20Lose%20-%20HTML%20Notebook.html).

[Click here to display the HTML version of the calculations (monotone prizes) in your web browser](https://stokehol.github.io/Playing-to-Lose/Playing%20to%20Lose%20(Monotone%20Prizes)%20-%20Maxima%20Notebook.html).
